#1
Рабочая папка — это файлы проекта, с которыми я сейчас работаю.

Индекс  — это область, куда я добавляю изменения,
которые хочу включить в следующий коммит.

Коммит — это сохранённая версия изменений в Git с описанием того,
что было изменено.

#2
Git — это система контроля версий, которая работает локально
и хранит историю изменений проекта.

GitHub — это онлайн-платформа, на которой можно хранить
Git-репозитории и работать с ними удалённо.

git diff показывает изменения в рабочей папке, которые ещё
не добавлены в индекс.

git diff --staged показывает изменения, которые уже добавлены
в индекс и попадут в следующий коммит.

#3
git status показывает текущее состояние рабочего дерева и индекса:
какие файлы изменены, какие добавлены в индекс, а какие ещё не отслеживаются.

git diff показывает различия между рабочей папкой и индексом.

git diff --staged показывает различия между индексом и последним коммитом.
